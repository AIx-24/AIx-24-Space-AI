# Ғарыштық миссияны басқарудың өзін-өзі қалпына келтіретін интеллектуалдық жүйесін әзірлеу
## Команда
AIx-24
## Жоба мақсаты
Ғарыштық аппарат миссиясының тұрақтылығын арттыру үшін энергия, температура
және миссия ресурстарын автономды түрде басқаратын жасанды интеллект
жүйесін әзірлеу.
## Мәселенің өзектілігі
Ғарыштық миссиялар барысында энергияның сарқылуы, температураның қауіпті
деңгейге жетуі және ресурстардың тиімсіз қолданылуы миссияның мерзімінен
бұрын тоқтауына алып келеді.
## Ұсынылатын шешім
Бұл жоба Reinforcement Learning (Q-learning) әдісіне негізделген
интеллектуалдық басқару жүйесін ұсынады. Жүйе қоршаған ортаның күйін
үздіксіз бақылап, тиімді басқару стратегиясын өздігінен үйренеді.
## Қолданылған технологиялар
- Python
- Reinforcement Learning (Q-learning)
- NumPy
- Matplotlib
## Эксперименттік апробация
Жүйе симуляциялық ортада тексерілді. Екі сценарий салыстырылды:
- Жасанды интеллектсіз басқару
- Жасанды интеллект негізіндегі басқару
Нәтижелер жасанды интеллект миссияның өмір сүру уақытын арттырып,
температураны қауіпсіз диапазонда ұстай алатынын көрсетті.
## Қорытынды
Ұсынылған интеллектуалдық жүйе ғарыштық миссиялардың тиімділігін арттыруға,
операциялық шығындарды азайтуға және аппараттардың қызмет ету мерзімін
ұзартуға мүмкіндік береді.
